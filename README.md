# 📊 Customer Segmentation Dashboard – Excel

## 📌 Project Overview
The Customer Segmentation Dashboard is an interactive Excel-based data analytics project designed to analyze customer demographics, purchasing segments, income levels, and customer growth trends.

The dashboard transforms raw customer data into meaningful insights using Excel Pivot Tables, Pivot Charts, and interactive filtering.

## 🎯 Project Objectives
- Analyze customer demographics and age groups.
- Understand customer distribution across different regions.
- Identify customer segments based on tenure.
- Analyze customer income brackets.
- Explore customer distribution by occupation and gender.
- Track customer growth over different years.

## 📂 Dataset Information
The dataset contains customer information, including:

- Customer ID
- Name
- Gender
- Age
- Generation
- Region
- Occupation
- Income
- Income Bracket
- Customer Segment
- Join Date
- Tenure
- Tenure Group
- Year
